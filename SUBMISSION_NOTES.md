# OMU · class submission notes

## Core task

Browse curated finds → filter by budget, category or collection city → open a piece → inspect its details and seller options → save it or visit the original marketplace.

## Test task

“You are furnishing your first apartment. You can spend up to CHF 200 on one piece and collect it in Zürich. Find something you would consider bringing home. Show where you would check its condition and where you would complete the purchase.”

Ask: (1) Was it possible to find a suitable piece without help? (2) Does OMU’s selection give a reason to start here, and is it clear where the purchase happens?

Do not write participant observations until a real person completes the task.

## Decision log

- Product direction: a small edited selection of secondhand furniture, with Compare available from every item.
- Change from the earlier room-inspiration direction: inspiration now connects to marketplace options and practical checks.
- Design decision: match the OMU Figma home typography, spacing, color, and product grid; keep the OMU wordmark on Home only.
- Data decision: label manually researched prices and collection areas as snapshots. One confirmed sold listing is explicitly marked sold.
- Known limits: the current catalog is not a live feed, some direct listing statuses could not be verified, and Living Room concept images represent similar-item searches.
- Next evidence needed: one independent task-based test and its observed issues.

## Publishing

The folder is ready for a static host. Upload the **contents of `omu-site`** to a GitHub repository or other static host. For GitHub Pages, choose Settings → Pages → Deploy from a branch → `main` → `/ (root)`. Then open the public URL on a phone and check images and the core flow.

GitHub sign-in was not available to the assistant, so no public URL was created here. The class brief requires a deployed URL and code on GitHub; the local folder alone does not meet that part.
