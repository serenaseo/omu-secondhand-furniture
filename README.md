# OMU website

Open `index.html` to run the website. No installation is required. Keep `app.js`, `styles.css`, and the `assets` folder beside it.

This is a mobile-first HTML, CSS, and JavaScript portfolio prototype rebuilt from the OMU Figma screens. It includes Home, The Edit, New Finds, Living Room, filters, saved finds, 10 named furniture details, Compare on every furniture detail, an all-pieces Compare index, menus, Profile.

The 10 named furniture models have three Figma image views each. Seven additional Living Room images are labelled as room inspiration and link to searches for similar items. The furniture images are styled concept visuals, not the seller's condition photos.

The price and pickup-area filters use manually researched snapshots. Seller listings can change or sell; the IKEA PS 2014 Herznach example is confirmed sold and labelled accordingly. Each piece links to current marketplace searches. OMU does not take payment; buying happens on the seller website.
